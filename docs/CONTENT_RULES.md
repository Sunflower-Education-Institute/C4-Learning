# Public content rules

- Each resource uses an immutable, unique `sourceId`.
- Provider names, trademarks, URLs, and IDs are not translated.
- English and Simplified Chinese descriptions remain separate.
- Use `en` and `zh-Hans` as language identifiers.
- Prices, trials, curriculum alignment, accreditation, and availability need an official source URL and verification date.
- Do not infer curriculum alignment from a country or region tag.
- Preserve editorial summaries separately from user reviews.
- Do not publish personal information, child information, private reviews, IP addresses, email addresses, or internal notes.
- Every resource image needs confirmed usage rights and useful alternative text, unless it is decorative.
- Unknown values remain absent or null according to the schema; do not replace them with guesses.
- Records with unresolved facts remain `needsReview` and must not be described as verified.
